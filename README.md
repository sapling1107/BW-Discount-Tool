寫給那個每次都在算「到底現在買划不划算」和會為了多 5% 點數而熬夜等活動的自己。
---

## 📱 使用方式

1. 輸入書籍資訊：
   - 書名（可選）
   - 原價
   - 折扣率
   - 使用點數
   - 折價券

2. 設定點數條件：
   - 活動倍數（預購請填 10）
   - 結帳回饋總％（例如 6%）

3. （可選）設定滿額條件

4. 點擊「新增書籍」即可看到結果

---

## ⚠️ 注意事項

- 點數計算以 BW 官方結帳為準，本工具為估算用途
- 活動與會員回饋不會疊加，會取較高者
- 點數顯示為 1 位小數
